# 0-Inbox — 灵感收集箱

## 目录用途

临时存放所有未经整理的素材，包括：
- 闪念灵感
- 看到的文章链接
- 会议记录草稿
- 截图、语音转文字
- 任何"先存下来再说"的内容

## 内容存放规则

1. **来者不拒**: 不用考虑分类，先扔进来
2. **命名规范**: `YYYYMMDD-简短描述.md`（如 `20260116-关于AI学习的想法.md`）
3. **定期清理**: 每周至少整理一次，将内容分发到对应目录
4. **不长期堆积**: Inbox 不是仓库，超过 2 周未整理的内容考虑删除或归档

## 使用示例

```
0-Inbox/
├── 20260116-读《认知觉醒》笔记.md
├── 20260117-Python异步编程疑惑.md
├── 20260118-产品需求会议草稿.md
└── 20260119-看到的好文章链接.md
```

## 整理流程

```
Inbox 素材
    ├── 是具体项目相关 → 1-Projects/
    ├── 是可复用的知识 → 2-Skills/（按道法术器分类）
    ├── 是参考资料     → 3-Resources/
    ├── 已过时/已完成   → 4-Archive/
    └── 可复用模板     → 5-Templates/
```
