# 4-Archive — 搁置区

## 目录用途

存放已完成的项目、过时的知识、不再活跃但仍有参考价值的内容。

Archive 不是垃圾桶，而是"冷藏库"——内容被冻结但可随时检索。

## 内容存放规则

1. **保留原结构**: 从其他目录移入时，保持原有文件夹结构
2. **添加归档说明**: 在文件夹内添加 `_archive_note.md`，记录归档原因和日期
3. **按年归档**: 建议按年份创建子目录，如 `2026/`、`2025/`
4. **定期清理**: 超过 2 年未访问的归档内容可考虑删除

## 归档说明模板

```markdown
# 归档说明

- **原位置**: [原目录路径]
- **归档日期**: YYYY-MM-DD
- **归档原因**: [已完成/已过时/已替代/其他]
- **是否可恢复**: 是/否
- **备注**: [任何需要说明的信息]
```

## 使用示例

```
4-Archive/
├── 2026/
│   ├── React学习项目/
│   │   ├── _archive_note.md
│   │   └── [原项目文件...]
│   └── 旧版博客模板/
│       └── _archive_note.md
└── 2025/
    └── Python爬虫项目/
        └── _archive_note.md
```
