# 知识库使用流程

## 日常使用流程

### 1. 收集素材（随时）

```
闪念/灵感/文章 → 0-Inbox/YYYYMMDD-描述.md
```

- 不用纠结分类，先扔进 Inbox
- 文件名用日期前缀，方便排序

### 2. 整理素材（每周）

```
0-Inbox/ 中的文件
    ├── 具体项目相关 → 1-Projects/项目名/
    ├── 可复用知识   → 2-Skills/（按道法术器分类）
    │   ├── 涉及思维原理 → 道-底层逻辑/
    │   ├── 涉及方法框架 → 法-方法论/
    │   ├── 涉及操作步骤 → 术-技巧步骤/
    │   └── 涉及工具使用 → 器-工具清单/
    ├── 参考资料     → 3-Resources/
    ├── 可复用模板   → 5-Templates/
    └── 没用的       → 删除
```

### 3. 写知识块（整理时）

1. 复制对应子目录的 `_template.md`
2. 按模板填写内容
3. 添加标签和关联链接
4. 更新 `6-Index/index.md` 索引

### 4. 项目管理（持续）

```
新项目启动
    ├── 在 1-Projects/ 创建项目文件夹
    ├── 创建项目 README.md
    └── 项目进行中...

项目完成
    ├── 在 4-Archive/ 创建年份目录
    ├── 移入项目文件夹
    └── 添加归档说明
```

### 5. 知识沉淀（每月）

```
回顾 2-Skills/ 中的知识块
    ├── "术"层知识多次实践 → 提炼为"法"层方法论
    ├── "法"层方法反复验证 → 悟出"道"层底层逻辑
    └── 更新关联链接和索引
```

## AI 协作流程

### 用 AI 整理 Inbox

将 Inbox 中的草稿发给 AI，让 AI 帮助：
- 分类到正确的目录
- 提炼为标准知识块格式
- 建立与已有知识的关联

### 用 AI 检索知识

告诉 AI 要找的内容，AI 可以：
- 搜索全库相关知识块
- 汇总跨目录的关联信息
- 生成知识地图和关系图

### 用 AI 生成模板

在 `5-Templates/` 中存放常用 AI Prompt，需要时直接调用：
- 文章总结 Prompt
- 代码审查 Prompt
- 知识提取 Prompt
