# 6-Index — 索引导航

## 目录用途

全库的索引导航中枢，提供知识库的内容索引、使用指南和常见问题解答。

## 文件说明

| 文件 | 用途 |
|------|------|
| `index.md` | 全库内容索引，按目录和主题分类 |
| `workflow.md` | 知识库使用流程指南 |
| `faq.md` | 常见问题解答 |

## 使用方式

1. **找内容**: 查看 `index.md`，按目录或主题检索
2. **学流程**: 查看 `workflow.md`，了解知识库的使用方法
3. **解疑惑**: 查看 `faq.md`，获取常见问题的解答
