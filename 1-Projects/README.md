# 1-Projects — 当前任务

## 目录用途

存放正在 actively 推进的任务和项目。每个项目一个子文件夹，完成后移入 `4-Archive/`。

适用内容: 当前正在进行的任务和项目

## 内容存放规则

1. **一项目一文件夹**: `项目名/` 下放该项目的所有文件
2. **项目 README**: 每个项目文件夹内创建 `README.md`，记录项目目标、进度、关键决策
3. **命名规范**: `项目名-简短描述/`（如 `React学习-前端框架入门/`）
4. **及时归档**: 项目完成后，整个文件夹移入 `4-Archive/`

## 使用示例

```
1-Projects/
├── React学习-前端框架入门/
│   ├── README.md           # 项目说明
│   ├── 01-JSX语法.md
│   ├── 02-组件生命周期.md
│   └── notes/              # 笔记目录
├── 个人博客搭建/
│   ├── README.md
│   ├── 技术选型.md
│   └── 进度记录.md
└── Python数据分析课程/
    ├── README.md
    └── week01-pandas基础.md
```

- [ ] 任务2
