# 5-Templates — AI操作模板

## 目录用途

存放可复用的 AI Prompt 模板、工作流模板、文档模板。这些模板设计为可直接被 AI 读取和执行。

## 内容存放规则

1. **一模板一文件**: 每个模板独立存放
2. **含使用说明**: 模板顶部注明用途、输入参数、预期输出
3. **可被AI调用**: 格式需适配 AI 解析（Markdown + 明确的占位符）
4. **版本管理**: 模板更新时保留旧版本注释

## 模板分类

### AI Prompt 模板
存放针对不同场景的 Prompt 模板，如：
- 文章总结 Prompt
- 代码审查 Prompt
- 知识提取 Prompt
- 周报生成 Prompt

### 工作流模板
存放多步骤工作流模板，如：
- 新项目启动流程
- 读书笔记工作流
- 技术调研流程

### 文档模板
存放标准文档格式模板，如：
- 项目README模板
- 会议记录模板
- 技术方案模板

## 使用示例

```
5-Templates/
├── ai-prompts/
│   ├── 文章总结.md
│   ├── 代码审查.md
│   └── 知识提取.md
├── workflows/
│   ├── 新项目启动流程.md
│   └── 读书笔记工作流.md
└── docs/
    ├── 项目README模板.md
    └── 会议记录模板.md
```

## Prompt 模板格式

```markdown
# [Prompt 名称]

## 用途
[这个 Prompt 解决什么问题]

## 输入参数
- {{param1}}: [参数说明]
- {{param2}}: [参数说明]

## Prompt 内容

你是[角色设定]。
请根据以下内容[任务描述]。

输入内容: {{param1}}
要求: {{param2}}

## 预期输出
[描述输出格式和质量要求]
```
