## 一、五运六气基础（任应秋原书核心 · 已 OCR 佐证）

### 1.1 十干化运（天干化五运）
> 〔已确认·任应秋原书 p.20, p.25〕「土主甲己，金主乙庚，水主丙辛，木主丁壬，火主戊癸」「甲己之岁土运统之；乙庚之岁金运统之；丙辛之岁水运统之；丁壬之岁木运统之；戊癸之岁火运统之」

| 天干 | 化运 | 备注 |
|---|---|---|
| 甲己 | 土运 | 甲阳→太宫（太过）；己阴→少宫（不及） |
| 乙庚 | 金运 | 乙阴→少商；庚阳→太商 |
| 丙辛 | 水运 | 丙阳→太羽（太过）；辛阴→少羽（不及） |
| 丁壬 | 木运 | 丁阴→少角；壬阳→太角 |
| 戊癸 | 火运 | 戊阳→太徵（太过）；癸阴→少徵（不及） |

**天符/岁会判定**（进阶同化）：岁运与司天/岁支之气相合，分天符、岁会、同天符、同岁会、太乙天符五类。〔已确认·任应秋原书 p.60-66〕

> 〔已确认·任应秋原书 p.41〕「逢子午年为少阴君火所主；丑未太阴湿土；寅申少阳相火；卯酉阳明燥金；辰戌太阳寒水；巳亥厥阴风木」

| 丑未 | 太阴湿土 | 太阳寒水 |

| 卯酉 | 阳明燥金 | 少阴君火 |
| 辰戌 | 太阳寒水 | 太阴湿土 |

### 1.3 五气经天 —— 十干化运的天文起源（附录补·进阶）
《素问·五运行大论》引《太始天元册》：「丹天之气经于牛女戊分；黅天之气经于心尾己分；苍天之气经于危室柳鬼；素天之气经于亢氐昴毕；玄天之气经于张翼娄胃。戊己分者，奎壁角轸，天地之门户也。」〔阎著发挥·附录一〕

| 五气 | 颜色 | 五行 | 所经星宿 | 对应天干 |
|---|---|---|---|---|
| 丹天之气 | 赤 | 火 | 牛、女（戊分） | 戊癸 |
| 黅天之气 | 黄 | 土 | 心、尾（己分） | 甲己 |
| 苍天之气 | 青 | 木 | 危、室、柳、鬼 | 丁壬 |
| 素天之气 | 白 | 金 | 亢、氐、昴、毕 | 乙庚 |
| 玄天之气 | 黑 | 水 | 张、翼、娄、胃 | 丙辛 |

**三种解释体系**（历代对十干化运的不同解读，互为补充非互斥）：
1. **五气经天说**（天文观测说）：《太始天元册》记录，天干化运有天象依据。
2. **五行胜负化运说**：天干从其所不胜之气而化（木从土、金从木等）。
3. **岁首天干相生化运说**：每年正月月建阳干按五行相生推岁运（五虎遁：甲己年正月丙寅→火生土→土运）。〔阎著发挥·附录 1.1-1.3〕

> ⚠️ 五气经天天文观测是否真实存在，现代天文学尚无定论，但反映古人将天象与五行系统关联的思维方式。〔阎著发挥·附录〕

### 1.4 岁运 / 主运 / 客运
- **岁运（大运/中运）**：统主一年，由年干定（1.1 表）。太过之年（阳干）大寒前 13 日交运，不及之年（阴干）大寒后 13 日交运。〔已确认·任应秋原书 p.27〕
- **主运**：年年始于太角（木）、终于太羽（水），固定五步，太少相生。〔已确认·任应秋原书 p.31-34〕
- **客运**：以本年岁运为初运，十年一周期，年年不同。〔已确认·任应秋原书 p.37-38〕

### 1.5 六气 / 主气 / 客气 / 间气
- **主气**：固定六步（厥阴风木→少阴君火→少阳相火→太阴湿土→阳明燥金→太阳寒水）。〔已确认·任应秋原书 p.45〕
- **客气**：随年支司天在泉排布，六步含司天、在泉及四间气。〔已确认·任应秋原书 p.55-56〕
- **客主加临**：客气加临主气，相生为「相得」、相克为「不相得」；「主胜为逆，客胜为从」（主气居常、客气暂至，宁从客不胜主）。〔已确认·任应秋原书 p.58-59〕

## 二、运气关系进阶（阎钧天附录 · 核心新增）

### 2.1 运气同化 / 从化 / 异化（三分法）
任应秋教材主要讲「同化」，阎著补「从化」「异化」，三分法更全面。〔阎著发挥·附录二〕

| 关系 | 定义 | 含义 | 举例 |
|---|---|---|---|
| 同化 | 运与气五行相同 | 同气相求，气候专一 | 土运遇太阴湿土司天（天符） |
| 从化 | 运与气相生 | 母子相生，气候顺和 | 水运遇厥阴风木司天（水生木），运从气化 |
| 异化 | 运与气相克 | 互相制约，气候反复 | 水运遇太阴湿土司天（土克水） |

**判断口诀**：同气=同化（专一），相生=从化（顺和），相克=异化（反复）。
步骤：①定岁运五行 → ②定司天之气五行 → ③看关系（同/生/克）。

**🔴 2026 丙午年实例**：水运太过 + 少阴君火司天，**水克火 = 运气异化**。运克气，运占主导，司天受制 → 寒水与热火交争，气候多变（先寒后热或寒热交替），疾病呈寒热交争特征。〔阎著发挥·附录二 + 与任应秋原书 p.26「岁水太过寒气流行」一致〕

### 2.2 左右间气（司天/在泉之四间）
客气六步中司天(三之气)、在泉(终之气)最重要，余四步为间气。〔阎著发挥·附录三〕

| 位置 | 名称 | 含义 |
|---|---|---|
| 初之气 | 在泉左间气 | 主大寒—春分气候 |
| 二之气 | 司天右间气 | 主春分—小满气候 |
| 三之气 | 司天 | 上半年核心 |
| 四之气 | 司天左间气 | 主长夏气候 |
| 五之气 | 在泉右间气 | 主秋气候 |
| 终之气 | 在泉 | 下半年核心 |

「左右」以面南而立定（司天在上，左东后、右西前）。间气辅助判断特定时段气候/疾病倾向。

### 2.3 南政与北政（争议最大）
出自《素问·至真要大论》，研究不同年份脉象差异（不应脉）。〔已确认·任应秋原书 p.84 + 阎著发挥·附录四〕

- **说法一（王冰注·主流）**：甲己年（土运）为南政，余八年为北政。土居中央面南而政。
- **说法二（陆筦泉）**：按岁支南北——亥子丑寅卯辰为南政，巳午未申酉戌为北政。

⚠️ 两说划分依据不同（天干 vs 地支），同一年可能结论不同，历代诸说不一。临床少用，作理论补充。核心应用：判「不应脉」（《至真要大论》北政少阴在泉则寸口不应等）。

### 2.4 亢害承制
「亢则害，承乃制，制则生化。」（《素问·六微旨大论》）某气亢盛到极点则有害，必有另一气承袭制约，制约后恢复生化。〔阎著发挥·附录六 + 任应秋原书 p.69 运用原则〕
例：木运太过克土，木亢至极则金来承制（金克木），脾病不至持续恶化。**太过之年未必全坏，自然有调节机制。**

### 2.5 胜复郁发
与亢害承制相关但侧重动态报复循环。〔阎著发挥·附录七〕
- **胜**：某气偏盛克所胜（主动方）。
- **复**：被克者之子来报复（如土被木克，土之子金来复木）。
- **郁**：被克太过，郁而不发。
- **发**：郁极突爆（如木郁极点发为风木）。
循环：胜→复→胜→复……直至平衡。临床意义：某气太过之病，复气当令时现转机（木太过脾病，秋金当令减轻）。

### 2.6 标本中气
六气各有标（三阴三阳名号）、本（五行本质）、中气（表里对应）。〔阎著发挥·附录八 + 任应秋原书体系〕

| 六气 | 本 | 标 | 中气 |
|---|---|---|---|
| 厥阴风木 | 木 | 厥阴 | 少阳相火 |
| 少阴君火 | 火 | 少阴 | 太阳寒水 |
| 太阴湿土 | 土 | 太阴 | 阳明燥金 |
| 少阳相火 | 火 | 少阳 | 厥阴风木 |
| 阳明燥金 | 金 | 阳明 | 太阴湿土 |
| 太阳寒水 | 水 | 太阳 | 少阴君火 |

**从化规律**：「少阳太阴从本（从本气化），少阴太阳从本从标，阳明厥阴不从标本从乎中。」（少阳从火化、太阴从湿化；阳明从太阴湿土化、厥阴从少阳相火化）

### 2.7 逐年交司时刻（精确化）
任应秋仅给大致节气，阎著提供精确到时辰的「交司时刻歌」。简化六气交司：〔阎著发挥·附录九〕

| 六气 | 交司节气（约） | 主时段 |
|---|---|---|
| 初之气 | 大寒（1/20） | 初春 |
| 二之气 | 春分（3/20） | 暮春 |
| 三之气 | 小满（5/21，司天加临） | 初夏 |
| 四之气 | 大暑（7/23） | 长夏 |
| 五之气 | 秋分（9/23） | 深秋 |
| 终之气 | 小雪（11/22，在泉加临） | 初冬 |

每年交司时刻因节气精确时刻而异，需查万年历定（精确到小时）。初学知大致节气即可。

## 三、运气体质划分（十大体质 · 阎钧天发挥）

按出生年岁运太过/不及分体质，系「治未病」在运气学的应用。〔阎著发挥·附录五，非《内经》原文，但与整体观一脉相承〕

| 出生年运气 | 体质特征 | 易感脏腑 | 调养方向 |
|---|---|---|---|
| 木运太过 | 肝气偏旺，易怒急躁 | 肝、脾 | 疏肝健脾，柔肝息风 |
| 木运不及 | 肝气不足，优柔 | 肝、肺 | 养肝润肺，滋水涵木 |
| 火运太过 | 心火偏亢，心烦失眠 | 心、肺 | 清心泻火，滋阴安神 |
| 火运不及 | 心气不足，畏寒乏力 | 心、肾 | 温心补肾，益气通阳 |
| 土运太过 | 脾湿偏盛，身重倦怠 | 脾、肾 | 健脾利湿，芳香化浊 |
| 土运不及 | 脾气虚弱，食欲不振 | 脾、肝 | 培土抑木，健脾益气 |
| 金运太过 | 肺气偏盛，咳嗽气逆 | 肺、肝 | 泻肺平肝，降气化痰 |
| 金运不及 | 肺气不足，易感外邪 | 肺、心 | 补肺养心，固表益气 |
| 水运太过 | 寒气偏盛，畏寒肢冷 | 肾、心 | 温阳散寒，交通心肾 |
| 水运不及 | 肾气不足，腰膝酸软 | 肾、脾 | 温肾健脾，补益精气 |

⚠️ 运气体质仅为一维，不涵盖生活习惯、后天环境、遗传；作「治未病」参考，非唯一依据。

### 🔴 老K 体质推算（1964 甲辰年）

## 四、2026 丙午年专项（双源交叉 · 任应秋原书佐证）

### 4.1 全年格局
> 〔已确认·任应秋原书 p.25-26〕「丙辛之岁水运统之……逢六丙年（丙寅/丙子/丙戌/丙申/丙午/丙辰）便为水运太过……岁水太过，寒气流行」；〔已确认·任应秋原书 p.41〕午年少阴君火司天、卯酉阳明燥金在泉

| 项目 | 结论 |
|---|---|
| 岁运 | **水运太过（太羽）** → 寒气流行 |
| 司天（上半年） | **少阴君火** |
| 在泉（下半年） | **阳明燥金** |
| 运气关系 | **异化**（水克火，运克气，运占主导）〔阎著发挥·附录二〕 |
| 全年基调 | 寒水与热火交争，气候多变，寒热交替；先天弱脏心、肾 |

### 4.2 六气六步 + 当下时段（2026-08-29 起）
> 〔已确认·任应秋原书 p.56 客主加临表〕

| 气 | 时段 | 主气 | 客气 | 加临 | 气候/民病要点 |
|---|---|---|---|---|---|
| 初之气 | 1/20–3/20 | 厥阴风木 | 太阳寒水 | 相得 | 寒始、腰臀痛 |
| 二之气 | 3/20–5/21 | 少阴君火 | 厥阴风木 | 相得 | 风行、目瞑目赤 |
| 三之气 | 5/21–7/23 | 少阳相火 | 少阴君火(司天) | 相得从 | 大火行、气厥心痛 |
| **四之气** | **7/23–9/23** | **太阴湿土** | **太阴湿土** | **同气** | **溽暑大雨、湿浊偏重；嗌干、鼽衄**（当下 8/29 仍在此） |

**当下眼病对应**：
- 四之气（湿土）：湿浊上犯头目 → 眼眵多、目痒、睑缘湿烂、视物昏蒙（儿童暑期用眼+湿热，结膜炎/麦粒肿易发）。
- 五之气（9/23后，燥火）：燥火伤津 → 眼干、目涩、红丝、畏光（正值门店促销尾段，眼干涩诉求升）。
