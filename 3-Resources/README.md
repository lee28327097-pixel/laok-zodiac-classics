# 3-Resources — 参考资源

## 目录用途

存放外部参考资料、学习资源、常用链接等。这些内容不需要主动处理，按需查阅即可。

## 内容存放规则

1. **按主题分类**: 每个主题一个子文件夹
2. **链接+摘要**: 存放链接时附上简短摘要，说明为什么收藏
3. **定期清理**: 失效链接及时删除
4. **标注来源**: 注明资源来源和获取日期

## 使用示例

```
3-Resources/
├── 技术文档/
│   ├── Python官方文档链接.md
│   └── React最佳实践合集.md
├── 课程资源/
│   ├── CS50课程笔记链接.md
│   └── MIT算法课资源.md
├── 好文收藏/
│   ├── 2026-如何高效学习.md
│   └── 2026-认知觉醒读书笔记.md
└── 工具网站/
    ├── 在线工具汇总.md
    └── 开源项目推荐.md
```

## 资源卡片模板

```markdown
# [资源标题]

- **链接**: [URL]
- **来源**: [作者/网站/书籍]
- **收藏日期**: YYYY-MM-DD
- **摘要**: [一句话说明这个资源讲了什么]
- **收藏原因**: [为什么觉得有用]
- **关联项目**: [[相关项目名称]]
```
