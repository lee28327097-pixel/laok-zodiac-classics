## 一、p25 · 七杀星问答（14 主星之第 6）

〔已确认·p25〕

**问答起首**：
> **七杀星所主若何。**
> **答曰：七杀南斗第六星也，属火金，乃斗中之将，寅成、败之孤辰，在午司斗柄，主於风号，主威作毋。**

〔已确认·p25·L1↔L2 互校说明〕：
- L1 OCR 输出「士吉星」→ L2 视觉 = 「第六星」✅
- L1「不秀逢天机耗雕僧道清閒」→ L2 视觉确认意思「不秀逢天机，耗则僧道清閒」✅
- L1「壬刑干道路者临」→ L2 实际是「庭毒年不長」✅

**入命特征**（OCR 片段，已校）：
- 主威作毋、逢刑总教於愿
- 秘疾瓦然身残、痰龈
- 「一身孤」

**核心要义（七杀本质）**：
- 「**成败之孤辰**」「**斗中之将**」= 七杀是**将星兼孤星**，主威也主孤
- 「在午司斗柄」= 七杀在午宫，掌斗柄，主宰权威
- 紫微全书将「将星/孤辰」并列一处，说明古人论命**先看性质（吉凶倾向）再看庙陷强弱**

**与天机对照**（同页对照）：
- 天机「不秀……僧道清閒」= 机月同梁一系，**机变聪敏但孤高**
- 七杀「成败之孤辰……主威」= 将星孤辰，**威猛但孤克**
- 两者皆「孤」，但**机是性孤，杀是命孤**——一个性格使然，一个格局所限

**对知让的弹药价值**：
- 之前 14 主星只有「按安星诀推」（一个锚点）
- 加上本书「七杀问答」原赋 = **双锚互校**
- 紫微侧「第一锚点 = 安星诀」、「第二锚点 = 古赋问答」，两源一致才升〔已确认·古赋〕

## 二、p30 · 天魁天钺辅星问答（科名之宿）

〔已确认·p30〕

**问答起首**：
> **天魁天钺星所主若何。**
> **希夷先生曰：魁斗中司科名、第爵禄不须问。**

〔已确认·p30·L1↔L2 互校说明〕：
- L1「希夷先生日」→ L2 = 「希夷先生曰」✅
- L1「看在天妻位」→ L2 = 「看在夫妻位」✅
- L1「若与廉屏票」→ L2 = 「若与廉贞同」✅
- L1「限步想逢」→ L2 = 「限步想逢」✅
- L1「女子添喜生男之生人」→ L2 实际 = 「必主女子添喜，生男之徵」

**入命/入夫妻特征**（OCR 片段，已校）：
- 「看在夫妻位，主人定二婚」
- 「若与廉贞同……少年必聚美」
- 「遇大难，必得贵人成」
- 「上界和合之神：若魁临命，守身更迭相守」
- 「更遇紫府日月扶助，小人不一，亦不为凶」
- 「限步想逢，必主女子添喜，生男之徵」

**歌曰**（天魁天钺）：
> 天乙贵人众所钦，命逢金带福弥深
> 飞腾各显人争羡，雅则俊雅入学功
> 名有成，生女容貌端庄，出众超群看四时

**核心要义**：
- 魁钺 = **司科名 / 第爵禄** = 古代科举功名之星
- 「上界和合之神」= **贵人星**性质，遇难必救
- 「限步想逢必主女子添喜」= 流年逢之，主喜庆（添丁）
- 与廉贞同 = 美事（少年得美眷）；与紫府日月 = 增福

**对知让的弹药价值**：
- 知让 `classical_sources.md` 已有魁钺零散条文，但**无希夷先生起首原文**
- 加上本书「魁斗中司科名」 = 知让可以**标注「魁钺为科名之主」的硬出处**
- 流年 / 限步用法：魁钺 = 流年喜庆（添丁得财），而非单纯庙陷论

## 三、L1↔L2 互校经验（沉淀入 skill）

| L1 OCR 错 | L2 视觉正 | 频次 |
|---|---|---|
| 卤 / 齿 | 凶 | 高频（古字形近） |
| 教 | 煞 | 中频（异体字） |
| 输 | 论 | 中频（行草） |
| 告 | 吉 | 中频（形近） |
| 屏 | 贞 | 中频（异体） |
| 士 | 六 | 中频（笔画残缺） |
| 屏票 | 廉贞同 | 中频 |
| 限步 | 限步 | 低频 |

**经验法则**：
- 看见「卤/齿/告/教」等单字孤悬，先睇上下文，多半系「凶/吉/煞」之误
- 看见「屏」「票」单字，多半系「贞」「论」之误
- 看见「士吉星」九成系「六吉星」（不吉不凶数第六）
- 看见「南斗第N星也，属X金」系古本紫微星赋标准句式
