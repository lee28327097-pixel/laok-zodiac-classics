## 知识库架构

本知识库采用 **PARA 架构**（Projects / Skills / Resources / Archive），
结合**道法术器**分类法，实现信息的可操作化管理。

### 目录总览

| 序号 | 目录 | 用途 | 可操作性 |
|------|------|------|----------|
| 0 | `0-Inbox/` | 灵感收集箱，未经整理的素材暂存区 | 待处理 |
| 1 | `1-Projects/` | 当前正在进行的任务和项目 | 高（有截止日期） |
| 2 | `2-Skills/` | 已掌握的技能和经验（按道法术器细分） | 中（持续积累） |
| 3 | `3-Resources/` | 参考资料、外部链接、文档存档 | 低（按需查阅） |
| 4 | `4-Archive/` | 已完成或搁置的内容归档 | 无（仅保留） |
| 5 | `5-Templates/` | AI 操作模板库，可复用的 Prompt 和工作流 | 按需调用 |
| 6 | `6-Index/` | 索引导航中枢，全库内容索引和使用指南 | 导航 |

### 道法术器分类（2-Skills 子目录）

| 层级 | 目录 | 含义 | 定位 |
|------|------|------|------|
| 道 | `道-底层逻辑/` | 第一性原理、底层思维 | 为什么这样做 |
| 法 | `法-方法论/` | 系统化方法、框架模型 | 怎么规划 |
| 术 | `术-技巧步骤/` | 具体操作、SOP 流程 | 怎么操作 |
| 器 | `器-工具清单/` | 工具选型、使用指南 | 用什么工具 |

## 快速开始

1. **新素材** → 先放入 `0-Inbox/`，定期整理分发
2. **新项目** → 在 `1-Projects/` 创建项目文件夹
3. **学到的知识** → 按"道法术器"分类写入 `2-Skills/` 对应子目录
4. **参考资料** → 存入 `3-Resources/`
5. **完成的任务** → 移入 `4-Archive/`
6. **常用模板** → 存入 `5-Templates/`
7. **查找内容** → 查看 `6-Index/index.md`

## 知识块格式

每个知识块遵循标准格式，确保 AI 可直接解析：

```
# [标题]
> **核心观点**: 一句话概括
## 案例说明
## 适用场景
## 关联知识
```

详见 `2-Skills/` 下各子目录的 `_template.md` 模板文件。

---

## 维护原则

- **原子化**: 一个文件只讲一个知识点
- **双链关联**: 用 `[[]]` 语法建立知识块之间的链接
- **定期整理**: 每周清理 Inbox，将素材归入对应目录
- **向上迁移**: "术"和"器"层的知识成熟后，提炼到"法"和"道"层
