# 器 — 工具清单

## 目录用途

存放工具选型、使用指南和工具对比，回答"用什么工具"的问题。

器是最具体的层级，记录具体工具的安装、配置、使用方法。

## 内容范围

- 工具选型对比（如Obsidian vs Notion vs Logseq）
- 安装配置指南（如环境搭建、插件配置、主题设置）
- 使用技巧（如快捷键、工作流配置、插件推荐）
- 工具清单汇总（如"前端开发工具清单""数据分析工具栈"）

## 内容存放规则

1. **版本标注**: 工具更新快，注明使用的版本和日期
2. **对比维度**: 工具对比需从多维度（价格、功能、学习曲线、生态等）
3. **配置文件**: 重要配置应附上配置文件内容或截图
4. **替代方案**: 推荐工具时附上备选方案
