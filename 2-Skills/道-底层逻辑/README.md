# 道 — 底层逻辑

## 目录用途

存放知识的"第一性原理"和底层思维模型。回答"为什么这样做"的问题。

这类知识具有最高的抽象层级和最长的时效性，是整个知识体系的根基。

## 内容范围

- 思维模型（如第一性原理、系统思维、临界知识）
- 底层规律（如复利效应、幂律分布、正反馈循环）
- 认知框架（如成长型思维、二八法则、奥卡姆剃刀）
- 哲学原则（如极简主义、长期主义、实用主义）

## 内容存放规则

1. **高度抽象**: 不涉及具体工具或步骤，聚焦"为什么"
2. **跨领域通用**: 道层知识应能适用于多个领域
3. **个人化表达**: 用自己的语言重述，而非照搬书本
4. **关联实践**: 必须能关联到具体的"法""术""器"层知识

## 使用示例

```
道-底层逻辑/
├── 学习的本质是建立心智模型.md
├── 复利效应-微小进步的长期价值.md
├── 费曼原理-能用大白话讲清楚才算真懂.md
└── 系统思考-见树木更见森林.md
```
