# 2-Skills — 经验复利

## 目录用途

存放已掌握的技能和经验，是知识库的核心区域。采用**道法术器**四层分类法，
让知识从具体工具向上沉淀为底层思维。

## 道法术器结构

```
2-Skills/
├── 道-底层逻辑/    ← 为什么这样做（第一性原理、思维模型）
├── 法-方法论/      ← 怎么规划（系统化方法、框架流程）
├── 术-技巧步骤/    ← 怎么操作（SOP、具体步骤）
└── 器-工具清单/    ← 用什么工具（工具选型、使用指南）
```

## 分类决策树

```
新知识进入
    │
    ├─ 涉及思维认知、底层原理？ → 道-底层逻辑/
    │
    ├─ 涉及系统方法、框架模型？ → 法-方法论/
    │
    ├─ 涉及具体操作、步骤流程？ → 术-技巧步骤/
    │
    └─ 涉及工具使用、选型对比？ → 器-工具清单/
```

## 知识块标准格式

每个知识块是一个 `.md` 文件，遵循统一结构：

```markdown
# [知识块标题]

> **核心观点**: 一句话概括核心洞察

## 案例说明
具体案例、实际场景、代码示例

## 适用场景
- 场景 1
- 场景 2

## 关联知识
- [[关联知识块名称]]
```

各子目录内有 `_template.md` 模板文件，可直接复制使用。

## 沉淀规则

- **新知识先入"术"或"器"**: 先记录具体操作和工具
- **成熟后向上迁移**: 多次实践后，提炼为方法论（法）或底层逻辑（道）
- **一个文件一个知识点**: 保持原子化，便于检索和链接
- **建立双链**: 用 `[[]]` 语法连接相关知识点，形成知识网络
