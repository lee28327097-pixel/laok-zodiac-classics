# 法 — 方法论

## 目录用途

存放系统化的方法和框架，回答"怎么规划"的问题。

法是道的具体化，是术的抽象化，提供可复用的思维框架和流程模板。

## 内容范围

- 学习方法（如费曼学习法、间隔重复、主动回忆）
- 工作框架（如PDCA循环、OKR、敏捷开发）
- 决策模型（如SWOT分析、决策矩阵、成本收益分析）
- 流程模板（如项目启动清单、代码审查流程、写作流程）

## 内容存放规则

1. **可复用**: 方法论应能在不同场景重复使用
2. **有步骤**: 即使是方法层，也应包含大致的执行步骤
3. **有道有术**: 每个方法应说明背后的"道"（原理）和配套的"术"（操作）
4. **适用边界**: 标注方法的适用条件和局限性
