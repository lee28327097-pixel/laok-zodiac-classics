# 术 — 技巧步骤

## 目录用途

存放具体的操作技巧和标准化流程（SOP），回答"怎么操作"的问题。

术是最贴近实操的层级，是可以照着做的"菜谱式"知识。

## 内容范围

- 操作步骤（如Git工作流、Docker部署步骤、Excel快捷键）
- 技巧诀窍（如代码调试技巧、写作润色技巧、演讲控场技巧）
- SOP流程（如新项目启动清单、每周复盘流程、读书笔记模板）
- 避坑指南（如常见错误及解决方案、踩坑记录）

## 内容存放规则

1. **具体可执行**: 步骤必须具体到"照着做就能完成"
2. **有截图有代码**: 尽量配以截图、代码示例
3. **标注前置条件**: 说明执行前需要什么环境、工具、知识
4. **记录踩坑**: 附上常见错误和解决方案

## 使用示例

```
术-技巧步骤/
├── Git分支管理操作流程.md
├── 用Anki制作间隔重复卡片.md
├── Python虚拟环境配置SOP.md
├── Markdown写作快捷键速查.md
└── VSCode高效调试技巧.md
```
